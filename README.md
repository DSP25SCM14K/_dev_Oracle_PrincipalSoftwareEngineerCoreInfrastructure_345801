# Dev Kumar — Core Infrastructure Portfolio

A responsive engineering portfolio for distributed systems and cloud infrastructure. The animated data-plane diagram, reliability engineering loop, full experience history, and project collection highlight high-throughput services, storage, resilience, and production operations.

Open `index.html` directly or serve this folder with a static web server. GitHub Pages publishes the repository root through the included Actions workflow.

- `index.html` — portfolio content and infrastructure architecture diagram
- `styles.css` — responsive layout and animation
- `script.js` — animated background, rotating focus text, reveals, and project search
- `.github/workflows/pages.yml` — GitHub Pages deployment
